Deskripsi Tugas Proyek Analisis dan Perancangan Sisten Informasi

Proyek ini bertujuan untuk melatih mahasiswa dalam menganalisis kebutuhan sistem informasi serta merancang model sistem yang terstruktur. Tahapan yang harus dilakukan adalah:

  1. Tentukan topik atau tema apa yang ingin di komputerisasi : memilih suatu proses bisnis atau aktivitas nyata yang masih d ilakukan secara manual, kemudian mengusulkan bagaimana proses tersebut dapat ditingkatkan melalui sistem komputerisasi. Topik harus relevan dengan dunia nyata, misalnya sistem reservasi, sistem antrian, atau sistem peminjaman.
  2. Membuat Diagram Konteks : Diagram konteks menggambarkan sistem secara keseluruhan dalam bentuk satu proses tunggal yang berinteraksi dengan entitas luar (aktor eksternal). Tujuannya adalah menunjukkan batasan sistem, aliran data masuk dan keluar, serta hubungan sistem dengan lingkungan eksternal.
  3. Menyusun Data Flow Diagram Level 0 (DFD 0) : DFD level 0 memecah sistem menjadi beberapa proses utama. Diagram ini menampilkan aliran data antar proses, data store (penyimpanan data), serta hubungan dengan entitas eksternal. DFD 0 memberikan gambaran lebih detail dibanding diagram konteks, namun tetap pada level makro.
  4. Membuat DFD Level 1 untuk Proses 1 - 3 : Dalam praktiknya, DFD Level 0 biasanya punya beberapa proses utama (misalnya Proses 1, Proses 2, Proses 3). Nah, ketika diminta bikin DFD Level 1, setiap proses itu harus diuraikan lebih detail. Jadi seharusnya dijelaskan dulu:
    • Proses 1 : apa aktivitas utamanya?
    • Proses 2 : apa yang dilakukan?
    • Proses 3 : Apa outputnya?

Ketentuan teknis tugas Pemrograman Antarmuka Pengguna

  • Halaman web terdiri dari struktur dasar: header, konten utama (multi-kolom), dan footer
  • Konten utama wajib memuat minimal satu tabel HTML yang relevan dengan tema kasus yang dipilih.
  • Tabel wajib menerapkan minimal satu penggunaan colspan dan/atau rowspan secara tepat.
  • Tabel dan tata letak halaman diformat menggunakan CSS eksternal (file .css terpisah dari .html).
  • Styling tabel minimal mencakup: border/border-collapse, padding, text-align, dan salah satu efek (zebra striping atau hover).
  • Tata letak multi-kolom disusun rapi dan konsisten (boleh menggunakan teknik yang sudah dipelajari pada pertemuan 1-2).
  • Kode HTML dan CSS ditulis rapi (indentasi konsisten) agar mudah dibaca dan dinilai.
